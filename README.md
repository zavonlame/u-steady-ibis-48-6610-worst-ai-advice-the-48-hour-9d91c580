An entry for the [make.fun](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580) competition **Worst AI Advice: The 48-Hour Tight Line Open** (u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580): one line of the worst possible advice an AI could give, in 140 characters or fewer, judged head-to-head by the house judge.

## The line

> If your computer freezes, pour hot water on the keyboard — the heat thaws the frozen programs.

## How it works

`main.ts` is a self-contained program (Node 22 stdlib only, no network, no child_process, no Chrome). The entry text is embedded in it — it reads no files at runtime — and it writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), checking the line stays within the gate: 1 to 140 characters, not only whitespace.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
